## STFA is an attempt to make a modular Touhou game

* The fangame is supposed to target x86_64-unknown-dragonfly triplet (DragonflyBSD operating system) by default, although it's also intended to be compatible with other POSIX systems.
* The game is supposed to have some sort of modularity and extensibility in its design - kind of inspired by Minecraft resource packs
* Because a certain DragonflyBSD enjoyer (that is, me) is running potato hardware, the game is supposed to be lightweight

## Requirements:

So far, the requirements are not known (because the game has not been written yet).
However, the initial estimates are:

Bare minimum:
* CPU: x86-64, with at least 4 threads
* Display: 640x480 @ 60Hz Progressive
* Speakers: Anything usable
* Keyboard: 4KRO
